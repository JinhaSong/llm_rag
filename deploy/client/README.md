# C++ 클라이언트

의사 질문 한 문장을 보내면 **문진단계 · 질문유형 · 숫자질문 여부 · 표제어 후보**를 받는다.
외부 라이브러리 없이 소켓만 사용하므로 별도 설치 없이 바로 빌드된다.

## 빌드

```bash
# Linux
g++ -std=c++17 -O2 -o gloss_client gloss_client.cpp

# Windows (MinGW)
g++ -std=c++17 -O2 -o gloss_client.exe gloss_client.cpp -lws2_32

# Windows (MSVC)
cl /std:c++17 /EHsc gloss_client.cpp ws2_32.lib
```

## 실행

```bash
./gloss_client "언제부터 아팠어요?"   # 한 문장 질의
./gloss_client                        # 인자 없으면 대화 모드 (빈 줄로 종료)
```

출력 예:

```
접속 대상: http://10.254.66.168:8777/api/keywords

질문        : 언제부터 아팠어요?
문진단계    : 통증 발생시점 / onset
질문유형    : 오픈형 (open)
숫자질문    : 예
범위외      : 아니오
표제어      : 112개
  1. 둘,이_11057
  2. 십,열_10919
  3. 갑자기,갑작스럽다,별안간,갑작스레_11896
  ...
```

## 설정 — `config.txt`

실행 파일과 같은 위치에 둔다.

| 키 | 설명 |
|---|---|
| `host` | 서버 주소. 사내망 `10.254.66.168`, 랜선 직결 시 `192.168.100.2` |
| `port` | `8777` = 표제어 1,087개 / `8779` = 표제어 121개 |
| `path` | `/api/keywords` (분류와 추천을 한 번에 처리) |
| `timeout_sec` | 응답 대기 제한. 신규 문장은 LLM 생성으로 수 초가 걸린다 |

## API 규격

`POST /api/keywords`

요청
```json
{ "question": "언제부터 아팠어요?" }
```

응답
```json
{
  "question": "언제부터 아팠어요?",
  "stage": "통증 발생시점",
  "subCategory": "onset",
  "qType": "open",
  "qTypeLabel": "오픈형",
  "isNumericQuestion": true,
  "outOfScope": false,
  "count": 112,
  "keywords": ["둘,이_11057", "십,열_10919", "..."],
  "glossSet": "1107",
  "repaired": null,
  "latencyMs": { "total": 2160, "classify": 10, "recommend": 2119 }
}
```

### 필드 설명

- **`qType`** `open`(오픈형) / `choice`(선택형) / `confirm`(확인형).
  질문이 자유 응답인지, 보기 중 선택인지, 예·아니오인지를 나타낸다.
- **`isNumericQuestion`** 답이 수로 표현되는 질문인지. 참이면 `keywords` 에
  0~10 숫자 표제어가 포함되므로 **인식 후보를 숫자로 좁힐 수 있다.**
  시점·기간 질문도 참이다 — 수포합(이틀·사흘·어제 등)을 표제어 풀에서 빼고
  `숫자 + 단위(날·개월·년) + 전` 조합으로 답하도록 했기 때문이다.
- **`keywords`** `"표제어이름_고유번호"` 형식. 이름에 쉼표가 들어갈 수 있으므로
  (`"둘,이_11057"`) 고유번호를 떼려면 **마지막 `_` 기준으로** 자른다.
- **`outOfScope`** 문진과 무관한 질문이면 참이고 `keywords` 는 비어 있다.
  단, 참이 아니어도 `count` 가 0일 수 있다(예: "성함이 어떻게 되세요?").
  **빈 결과 판단은 `count` 로 하는 것이 안전하다.**
- **`repaired`** 분류 라벨이 서버 내부에서 보정되면 `{from, to}` 가 들어온다.
  호출측이 따로 처리할 것은 없다.
